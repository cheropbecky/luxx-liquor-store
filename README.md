
# 🥂 Luxx Liquor Store

Welcome to **Luxx Liquor Store** — an elegant, dark-themed online liquor shop designed for a seamless shopping experience across all devices. Built for beauty, performance, and practice.

> 🍷 *“Where elegance meets e-commerce.”*

---



---

## ✨ Key Features

- 🛍 Clean homepage with featured product categories: Wines, Vodka, Beer, Soft Drinks, and more
- 🛒 Fully functional shopping cart (add/remove items, view totals)
- 📩 Checkout page powered by **EmailJS** – no backend required!
- 🎨 Dark-themed, animated user interface
- 📱 Mobile-first, fully responsive layout
- ⚡ Smooth fade-in and slide-in animations

---

## 💻 Technologies Used

- **HTML** – Page structure and content
- **CSS** – Styling, layout, and responsiveness
- **JavaScript** – Dynamic behaviors (cart logic, filters, events)
- **EmailJS** – Handles checkout form submissions to email
